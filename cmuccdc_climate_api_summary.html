1. Overview & Authentication

  • Base URL: https://open-api.cmuccdc.org
  • Registration: https://open-api.cmuccdc.org/main/register (General Public activates immediately with a 10-station limit; Student/Researcher, Civil Society, Private, Government, and MOU accounts require admin approval).
  • Default Scope: Outdoor stations only (Indoor or combined Indoor+Outdoor requires special permission from CCDC).
  • Attribution Requirement: Must credit CCDC CMU / DustBoy on the dashboard, e.g. "ข้อมูลนี้ได้รับการสนับสนุนจากศูนย์ข้อมูลการเปลี่ยนแปลงสภาพภูมิอากาศ มหาวิทยาลัยเชียงใหม่ (CCDC CMU)" or "ข้อมูลจากเครื่องตรวจวัดคุณภาพอากาศ DustBoy" (or display the DustBoy / CCDC CMU logo).
  • CCDC Contact: Email dustboy.3e@gmail.com | Tel: 064-069-1698

2. Climate / Air Quality APIs for This Dashboard (DustBoy API)

Note: FloodBoy API (/api/floodboy/*) on the same portal is for water-level/flood monitoring only and is not needed for PM2.5/Temperature climate panels.

[A] Real-Time Hourly Endpoints (Map Pins, 5 km PM2.5 Overlay & Live Readings)

Method Endpoint Parameters Allowed Roles Dashboard Usage
GET /api/dustboy/stations None Private, Gov, MOU All online stations with coordinates & live hourly readings (replaces static station_data.json + mock pm25/temp in regionalStations & 5 km overlay).
GET /api/dustboy/station Configured station ID All accounts (Public ≤ 10 stations) Single-station real-time hourly reading & sensor metadata.
GET /api/dustboy/nearme/{latitude}/{longitude}/{distance} latitude, longitude, distance (max 20 km) Private, Gov, MOU Find online stations within 20 km of a site or pinned home (pinStudentHome() Top 3 lookup).
GET /api/dustboy/province Province selection CSO, Private, Gov, MOU Real-time hourly readings grouped by province (e.g., Chiang Mai, Lamphun, Chiang Rai).
GET /api/dustboy/areahealth Health region CSO, Private, Gov, MOU Real-time hourly readings grouped by Ministry of Public Health region (เขตสุขภาพ).
GET /api/dustboy/geography Geographic region Private, Gov, MOU Real-time hourly readings by geographical region (e.g., Northern Thailand).

[B] Historical Hourly Time-Series & Bulk Endpoints (Trend Charts & History)

Method Endpoint Parameters Allowed Roles Dashboard Usage
GET /api/dustboy/data30day/{id} id (station ID) Private, Gov, MOU Past 30 days hourly readings for short-term trend chart (envChart) & location comparison.
GET /api/dustboy/data1year/{id} id (station ID) Student/Researcher, Private, Gov, MOU Past 1 year hourly readings (supports 180-day observed history in forecast-model.js).
GET /api/dustboy/data5year/{id} id (station ID) Student/Researcher, Private, Gov, MOU Past 5 years hourly readings for multi-year seasonal baselines.

GET /api/download/data30day/{id} id (station ID) Web UI Download Direct 30-day station dataset download (Excel/export).

4. Dashboard Integration Mapping

  • Map Markers & 5 km PM2.5 Area Overlay (index.html): GET /api/dustboy/stations (or /api/dustboy/province) to replace mocked pm25/temp in regionalStations and userSites[].stations.
  • Nearest Station Lookup on Pin Drop (pinStudentHome()): GET /api/dustboy/nearme/{lat}/{lng}/{distance} (distance ≤ 20 km).
  • Time-Series Charts & Historical Exposure (envChart, forecast-model.js): GET /api/dustboy/data30day/{id} (30-day trend) and GET /api/dustboy/data1year/{id} (180-day / annual history).
  • 7-Day PM2.5 Forecast (forecast-model.js, care-ops-model.js): GET https://pm25_migration.cmuccdc.org/v1/stations/forecast provides 7-day point pm25 values (forecasts[].pm25) for 542 stations matched by station_id / lat / lon.
Fields Still Requiring Mock-up or External Weather APIs:
  • Forecast Temperature: Not returned by /v1/stations/forecast yet — continue using mock-up temperature (or pair with TMD / Open-Meteo).
  • Forecast Confidence Intervals (lower, upper): /v1/stations/forecast returns point pm25 means only — continue using mock-up bounds for LhsForecast.triple(mean, lower, upper) until prediction intervals are added.
  • Heat Index: Derive from observed station Temperature + Relative Humidity or pair with a weather API for calculateCompositeRisk.
